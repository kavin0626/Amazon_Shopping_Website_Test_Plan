# Amazon Shopping Website Test Plan

## About

This project contains a test plan and test cases for the Amazon shopping website.

## Testing Areas

* User Registration
* User Login
* Product Search
* Product Details
* Add to Cart
* Wishlist
* Checkout
* Order Management
* UI Testing
* Functional Testing

## Objective

The main objective is to check whether the important features of the Amazon shopping website work correctly and meet the expected requirements.

## Tools Used

* Microsoft Excel
* Manual Testing

## Test Plan

The test plan includes:

* Test Case ID
* Test Scenario
* Test Steps
* Expected Result
* Actual Result
* Test Status

## Conclusion

This test plan helps identify functional and usability issues in the Amazon shopping website and ensures that the major shopping features work as expected.
